# AskSoe

AskSoe is the universal decision layer — one interface to ask, understand, and act.

## Getting Started

Clone the repository and install dependencies:

```bash
git clone https://github.com/yourusername/asksoe.git
cd asksoe
npm install
```

## Running Locally

### Server

```bash
npm run dev
```

### Client

```bash
cd client
npm install
npm run dev
```

## Deployment

You can deploy this project to Railway or your preferred platform.

- Set up your `.env` file with the required environment variables (see `.env.example`).
- Push your code to your deployment platform.
